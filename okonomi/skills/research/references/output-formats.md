# Output Formats

Templates for the structured outputs this skill produces. Choose and combine based on what the user needs.

## Concept Brief

Full visual direction for complex or multi-image concepts. Use for projects that need a cohesive visual system, not just a single image.

```markdown
# [Concept Name]

## Core Concept
[1-2 paragraphs: emotional intent, what the viewer should feel, the central tension or idea]

## Visual Direction

### Mood & Atmosphere
[Emotional texture: warm/cold, intimate/vast, calm/tense]

### Color Palette
[Primary, secondary, accent colors with hex codes or descriptive names. Temperature. Contrast level.]

### Lighting
[Quality, direction, source, temperature. Reference specific lighting setups.]

### Composition
[Framing approach, spatial relationships, negative space strategy]

### Texture & Surface
[Material quality: rough/smooth, organic/geometric, matte/reflective]

### Movement (if applicable)
[Motion vocabulary: slow drift, explosive, mechanical, organic]

## Style References
[For each reference: name, what it specifically contributes — not just "like this" but what it teaches about light, space, texture, or mood]

## Cultural / Historical Context
[Relevant traditions, movements, or visual lineage that informs the concept]

## Technical Notes
[Medium-specific: prompt keywords, camera settings, illustration techniques, model-specific advice]
```

## Prompt Package

For AI image generation. Not just a single prompt — a system for iteration.

```markdown
# [Concept Name] — Prompt Package

## Core Prompt
[Ready-to-use prompt structured for the target model]

## Modifiers
[Swappable variations — different lighting, different angles, different moods]

- Lighting variants: [list]
- Composition variants: [list]
- Style variants: [list]

## Negative Prompt
[Elements to exclude, if model supports it]

## Parameters
- Aspect ratio: [recommendation]
- Style weight: [if applicable]
- Model-specific settings: [seed, steps, CFG, etc.]

## Iteration Notes
[How to evolve: what to try next, what levers to pull, what to adjust if results miss the mark]
```

## Exploration Document

Freeform creative exploration for open-ended concepts.

```markdown
# [Concept Name] — Exploration

## Starting Point
[The seed idea and what makes it interesting]

## Threads

### Thread 1: [Direction Name]
[Visual language, references, what this direction emphasizes]

### Thread 2: [Direction Name]
[Visual language, references, what this direction emphasizes]

### Thread 3: [Direction Name]
[Visual language, references, what this direction emphasizes]

## Tensions & Contrasts
[Oppositions that drive visual interest: old/new, organic/digital, intimate/monumental]

## Open Questions
[Prompts for further thinking, unresolved creative decisions]
```

## Photography Direction

For planned shoots — human photographer or AI-simulated photography.

```markdown
# [Concept Name] — Photography Direction

## Concept
[Central idea and visual story]

## Shot List
| # | Framing | Angle | Subject | Notes |
|---|---------|-------|---------|-------|
| 1 | [wide/medium/close] | [eye/low/high] | [description] | [key detail] |

## Lighting Direction
[Quality, source, temperature, mood. Reference specific setups from visual-language.md]

## Styling / Art Direction
[Wardrobe, props, location, set design]

## Post-Processing Direction
[Color grading, tone, grain, contrast treatment]

## Mood References
[Specific images, films, photographers to channel]
```
